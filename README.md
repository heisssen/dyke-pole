# Дике Поле — система для Foundry VTT v14

Неофіційна система для настільної рольової гри **«Дике Поле»** (рушій Wild Words) у Foundry VTT 14.

**Встановлення:** Foundry → *Game Systems* → *Install System* → *Manifest URL*:

```
https://github.com/heisssen/dyke-pole/releases/latest/download/system.json
```

## Що вміє

- **Аркуш персонажа**
  - походження, передісторія, роль;
  - 12 навичок і 3 знання: клік по кружечку змінює значення, клік по кубику кидає;
  - лічильники Степу й Руїни: трек на 3 сам переходить у рівень і пише картку в чат;
  - прагнення: задовільнення прибирає позначку лічильника; зв'язки;
  - аспекти з треками й здібностями: (п) дає перевагу, «використай» списує позначку;
  - тимчасові аспекти (користь і кривда);
  - ресурси з лімітами й тегами; уламки, які можна використати;
  - проєкти розвитку з довжинами за правилами.
- **Кидок**: дія, реакція, талан, контроль уламка, перевірка рейтингу табору, завдання (збір, створення, відновлення, вантаж).
  - Переваги з аспектів і спорядження, зрізи, вплив, твіст на дублях.
  - Нуль кісток означає кидок без Тріумфу.
  - Картка в чаті одним кліком ставить позначки на трек загрози чи перешкоди.
- **Аркуш табору**: рейтинги до 4, лічильник небезпеки до 10, вантаж, фракції з треком впливу, аспекти під контролем фракцій, проєкти.
- **Загроза**: складність, аспекти з треками, які разом утворюють трек загрози, дивацтва, ресурси, замирення й вигнання.
- **Панель «Треки»**: подорожі з ключовими фразами періодів, перешкоди й таймери (зокрема приховані), лічильник небезпеки активного табору, періоди відпочинку.
